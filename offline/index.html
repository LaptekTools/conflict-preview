What this preview can tell you

It recognizes a strict Syncthing conflict-name format and compares selected UTF-8 file bytes. Limits: 200 files, 4 MiB per file, 24 MiB per selection. Binary, non-UTF-8 and unfamiliar names need manual review. Dropbox names are not supported.

“Identical bytes” applies to the selected snapshots, not your live sync folder. Filenames are grouping hints, not verified history. No automatic winner or merge. The JSON report contains filenames, sizes and hashes; keep it private if those names are sensitive.

Use this tool offline

After one successful online visit, this browser can keep a copy of the tool for later. Your selected files and comparison reports are not saved in that copy. Clearing browser data removes offline availability.

Privacy and licence

Comparisons run in this page. No account, analytics, advertising, purchase or file upload. The hosting provider can log ordinary page and update requests, including IP addresses.
